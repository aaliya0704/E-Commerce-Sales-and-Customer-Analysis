# E-Commerce Sales and Customer Analysis

An exploratory data analysis (EDA) project using the **Online Retail dataset** from the UCI Machine Learning Repository to analyze e-commerce sales, customers, products, countries, transactions, and revenue trends over time.

## Project Overview

The goal of this project is to explore an e-commerce transaction dataset and extract meaningful business insights using Python, Pandas, Matplotlib, and Seaborn.

The analysis focuses on:

- Overall revenue generation
- Product performance
- Sales volume by product
- Customer revenue contribution
- Country-level sales performance
- Monthly revenue trends
- Country and month revenue patterns
- Average monthly revenue by country
- Transaction behavior
- Relationship between quantity and revenue
- Cancellations and negative transactions

## Dataset

This project uses the **Online Retail Dataset** from the UCI Machine Learning Repository.

The dataset contains transactions from a UK-based online retail company between **December 2010 and December 2011**.

### Dataset Source

**Online Retail Dataset — UCI Machine Learning Repository**

Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository.

The dataset is available under the **CC BY 4.0** license.

### Dataset Features

Important columns include:

| Column | Description |
|---|---|
| `InvoiceNo` | Unique invoice/transaction number |
| `StockCode` | Product/item code |
| `Description` | Product description |
| `Quantity` | Number of items purchased |
| `InvoiceDate` | Date and time of transaction |
| `UnitPrice` | Price per unit |
| `CustomerID` | Unique customer identifier |
| `Country` | Customer's country |

## Data Preparation

The `InvoiceDate` column was converted from a string/object format into a datetime format to allow time-based analysis.

```python
df["InvoiceDate"] = pd.to_datetime(df["InvoiceDate"])
```

A new `Revenue` column was created using:

```python
df["Revenue"] = df["Quantity"] * df["UnitPrice"]
```

This represents the revenue associated with each transaction.

A `Month` column was also created for monthly analysis:

```python
df["Month"] = df["InvoiceDate"].dt.to_period("M")
```

The dataset contains negative quantities and negative revenue values, which can be associated with cancellations or returns. These records were retained during the exploratory analysis so that their effect on the transaction data could be observed.

## Analysis Performed

### 1. Revenue Analysis

Calculated transaction revenue using:

```python
df["Revenue"] = df["Quantity"] * df["UnitPrice"]
```

The analysis examined the overall revenue generated by the e-commerce business.

### 2. Monthly Revenue Analysis

Revenue was aggregated by month to examine how sales changed over time.

```python
monthly_revenue = df.groupby("Month")["Revenue"].sum()
```

A line chart was used to visualize the monthly revenue trend.

This helped identify periods of relatively high and low revenue throughout the dataset's time period.

### 3. Quantity vs Revenue

A scatter plot was created to examine the relationship between the quantity of items in a transaction and the resulting revenue.

```python
sns.scatterplot(x="Quantity", y="Revenue", data=df)
```

The visualization showed a generally positive relationship between quantity and revenue.

Transactions involving larger quantities generally produced higher revenue, although several extreme positive and negative values were present.

Since revenue was calculated directly from quantity and unit price, this relationship is expected and should not be interpreted as proof that quantity independently causes revenue.

### 4. Country × Month Revenue Analysis

A pivot table was created to analyze revenue generated by each country during each month.

```python
monthwise_revenue = pd.pivot_table(
    df, values="Revenue", index="Country", columns="Month", aggfunc="sum"
)
```

The resulting table contains:

- Countries as rows
- Months as columns
- Total revenue as values

A heatmap was then used to visualize the country-month revenue patterns.

```python
sns.heatmap(monthwise_revenue.head(10), annot=True, fmt=".0f")
```

This visualization made it easier to identify periods of relatively high and low revenue for individual countries.

### 5. Top Customers by Revenue

Customer revenue was calculated by grouping transactions by `CustomerID`.

```python
top_customers = df.groupby("CustomerID")["Revenue"].sum().sort_values(ascending=False)

display(top_customers.head(10))
```

This identified the customers who generated the highest total recorded revenue.

### 6. Country × Product Revenue Analysis

A pivot table was created to examine the total revenue generated by individual products in different countries.

```python
country_product_revenue = pd.pivot_table(
    df, values="Revenue", index="Country", columns="Description", aggfunc="sum"
)
```

This analysis demonstrated how product-level revenue varied across different countries.

Because the dataset contains a large number of unique product descriptions, the resulting pivot table is very wide. It was therefore used primarily for aggregation and exploration rather than as a full visualization.

### 7. Top Products by Revenue

Products were ranked according to their total recorded revenue.

```python
product_revenue = (
    df.groupby("Description")["Revenue"].sum().sort_values(ascending=False)
)

display(product_revenue.head(10))
```

The top results included:

- `DOTCOM POSTAGE`
- `REGENCY CAKESTAND 3 TIER`
- `WHITE HANGING HEART T-LIGHT HOLDER`
- `PARTY BUNTING`
- `JUMBO BAG RED RETROSPOT`
- `RABBIT NIGHT LIGHT`
- `POSTAGE`

Postage-related entries such as `DOTCOM POSTAGE` and `POSTAGE` were treated separately from physical merchandise when interpreting product performance.

Among the physical merchandise in the top results, `REGENCY CAKESTAND 3 TIER` generated the highest recorded revenue.

### 8. Top Products by Quantity

Products were also ranked according to total quantity sold.

```python
product_quantity = (
    df.groupby("Description")["Quantity"].sum().sort_values(ascending=False)
)

display(product_quantity.head(10))
```

The highest recorded quantity was:

- `WORLD WAR 2 GLIDERS ASSTD DESIGNS` — **53,847 units**

Other high-volume products included:

- `JUMBO BAG RED RETROSPOT`
- `ASSORTED COLOUR BIRD ORNAMENT`
- `POPCORN HOLDER`
- `PACK OF 72 RETROSPOT CAKE CASES`
- `WHITE HANGING HEART T-LIGHT HOLDER`
- `RABBIT NIGHT LIGHT`

The analysis demonstrates that the products with the highest quantity sold are not necessarily the products generating the highest revenue because revenue also depends on unit price.

### 9. Average Monthly Revenue by Country

The country × month revenue pivot table was used to calculate the average monthly revenue for each country.

```python
monthly_average = monthwise_revenue.mean(axis=1).sort_values(ascending=False).head(5)

display(monthly_average)
```

The top five countries by average recorded monthly revenue were:

| Country | Average Monthly Revenue |
|---|---:|
| United Kingdom | 629,831.26 |
| Netherlands | 21,897.04 |
| EIRE | 20,252.06 |
| Germany | 17,053.71 |
| France | 15,184.92 |

The United Kingdom had a substantially higher average recorded monthly revenue than the other countries in the top five.

The calculation uses the available monthly revenue values for each country. Missing country-month combinations are ignored by Pandas when calculating the mean.

## Key Findings

The EDA produced several observations about the dataset:

- Revenue varied considerably from month to month.
- The United Kingdom generated the largest share of recorded revenue among the countries analyzed.
- The Netherlands, EIRE, Germany, and France followed the United Kingdom among the countries with the highest average recorded monthly revenue.
- Several products appeared among both the highest-revenue and highest-quantity lists.
- `WORLD WAR 2 GLIDERS ASSTD DESIGNS` had the highest recorded quantity sold, with 53,847 units.
- `REGENCY CAKESTAND 3 TIER` generated the highest recorded revenue among physical merchandise in the top revenue results.
- Postage-related descriptions appeared among the highest-revenue entries and should not be interpreted as physical product sales.
- Country-level revenue varied significantly across months.
- Negative revenue and quantity values were present in the dataset, reflecting transactions associated with returns or cancellations.
- The relationship between quantity and revenue was generally positive, which is expected because revenue is calculated using quantity and unit price.
- The products with the highest sales volume were not necessarily the products generating the highest revenue.
